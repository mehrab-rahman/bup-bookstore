# Authorized E-Book files

Place only PDF files you have permission to distribute in this folder.

Example: put `software-engineering.pdf` here, then sign in as the demo admin → Books & eBooks → Edit → enter `assets/ebooks/software-engineering.pdf` in the digital edition field and confirm permission.

The file must actually exist. Entering its name in the admin panel does not upload or create it. Alternatively, enter an authorized HTTPS provider link. Test the link before sharing the website.

No textbook PDF files are bundled. Books without configured digital editions offer an E-Book request.

Browser-side login cannot protect files in this folder. For paid or restricted digital content, use a backend with entitlement checks and short-lived download URLs; do not place protected PDFs in a public static folder.
